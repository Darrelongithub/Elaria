## Verified implementation

- `_observation_linux.atspi()` requires positive window dimensions and size
  agreement within 8 logical pixels. Screen-origin matches retain coordinates;
  otherwise a near-zero origin (within 8 pixels on each axis) authorizes adding
  Hyprland's window `at` origin to the window and every valid descendant rect.
  This is exact addition, not snapping, scaling, or inferred placement.
- Only one eligible active window is accepted. Size/origin disagreements and
  multiple candidates remain fail-closed. Invalid AT-SPI sentinel coordinates
  remain excluded before translation.
- Helper JSON carries rejection reason counts; `_elements()` journals those
  counts as `observation.atspi.windows`. `capture()` journals helper OS/process
  failures as `observation.atspi.snapshot` before using an empty snapshot.
  These logs contain neither accessible names nor subprocess stderr/commands.
- No changes to confidence gates, sensitive refusals, grounding, portal capture,
  point-only behavior, or `OWNERS.yaml`.
