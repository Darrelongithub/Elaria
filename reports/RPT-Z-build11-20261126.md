# BUILD-11 — partial implementation and remaining work

The existing errand runner already supplied opt-in discovery roots, ZIP manifest discovery, byte-window continuation and untrusted observation envelopes. This change hardens that seam: ancestor symlink checks on discovery roots and index hits, root-constrained index fallback, unsafe ZIP member filtering, strict UTF-8 window boundaries, change detection between errand windows, and a bounded first-window schema description with explicit incomplete/parse-error states. Discovery does not extract archive members. Errand continuation remains bounded by the configured step budget and reports when it stops.

The indexer now streams plain text into SQLite chunks rather than reading and silently cutting it at 200,000 characters. Chunk insertion rolls back on generator failure. Legacy bounded extraction now reports over-limit errors rather than indexing a silently shortened result. Large text files from older indexes are re-indexed (currently on each scan) to repair earlier truncation.

Verification: `python -m pytest -q tests/test_build11_streaming.py tests/test_z_errand_runner.py tests/test_phase3_organiser.py` — 57 passed. New tests exercise a gardening CSV corpus, a large indexed file's tail, ZIP discovery and protected paths, UTF-8 boundaries, malformed/partial JSON and transactional rollback.

**BUILD-11 is not complete.** First-window inspection is not a streaming structural parser: JSON/JSONL/CSV records spanning windows are not yet parsed as complete structured records, and large minified JSON cannot be validated incrementally. PDF and OOXML extraction remain non-streaming and can use large memory; bounded extraction rejects over-limit output but does not bound the parser's intermediate memory. ZIP pagination repeatedly hashes/decompresses the member; tar and SQLite inspection are not implemented. File path checks do not provide race-free `openat`/no-follow handling; source changes during the initial hash/read or in-place edits with restored metadata can escape the checks. Legacy indexed non-text documents are not automatically reindexed, and an extraction failure on an existing document can leave stale indexed content. Existing privacy isolation and end-to-end task composition are not established by these tests. No claim of full structured streaming or closure of GAP-2/GAP-3 is made.
