# BUILD-11 — implementation and verification (updated)

## Delivered

- Opt-in discovery roots remain independent of organiser roots. Discovery searches paths and metadata, includes non-text filenames, and reads ZIP and TAR manifests without extracting files. Member count, unsafe names and expansion are guarded; skipped/failed walks are reported.
- Read-only byte windows preserve UTF-8 boundaries, record their continuation and provenance, and detect changed content across windows. File reads traverse directory descriptors with `O_NOFOLLOW`; ZIP/TAR member reads use the same guarded opening. Data and schema observations are `trusted=False`; never-send sources are refused at cloud-bound structured reads and indexed chunk pagination.
- `assistant.structured_reader` pages JSON arrays/objects, JSONL, CSV/TSV (including multiline records), HTML text and ZIP/TAR members with a hash-bound record cursor. It validates encountered structure, reports errors and record/resource limits instead of dropping data, and labels partial inspection as incomplete. Errands invoke structural inspection and record the result without placing the sample in their step journal. Bounded indexed-document chunk pagination is available.
- Plain text indexing streams directly to transactional chunk writes. Extraction errors are surfaced and stored as error status, with stale content excluded from indexed text search and embedding retrieval. Existing indexes are migrated and re-extracted once to repair legacy truncation. PDF extraction is output-bounded; OOXML member expansion and output are capped and fail loudly.
- Tests cover a >200 KB minified plant inventory, multiline workshop-style records, archive manifests and member reads, malicious content as data, changed source detection, UTF-8 splits, protected/symlink paths, expansion/record limits, error rollback and stale-index suppression.

## Remaining blockers — BUILD-11 is not closed

- The existing errand analyzer still consumes raw byte windows using its heuristic extractor, not the structured record pages. Inspection samples structure but does not validate the entire file as the errand proceeds. A corrupt trailing JSON/CSV record may therefore escape detection in the errand path even though `structured_reader.read_batch` reports it when paged to EOF.
- Individual structured records exceeding the hard limit fail loudly; nested single JSON records cannot be streamed as separate events. SQLite structured inspection is not implemented. PDF/OOXML use bounded extraction with explicit over-limit errors, not full pagination; archive pagination replays the source and can be slow.
- Discovery's `os.walk` and some metadata checks are not descriptor-relative, so concurrent directory replacement can race discovery even though actual file-content opens use no-follow descriptors. The broader pre-existing memory recall/cloud privacy path is not proven by this lane's tests.

These are substantive parts of the requested full streaming / protected-path guarantees. Do not treat this PR as closing GAP-2 and GAP-3 until those issues are addressed.
