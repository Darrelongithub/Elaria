# CLONES 2026-11-26 — Coolify & Browser Use (manager find-first)

Owner-requested lookups. Verified via GitHub API 2026-11-26.

## Coolify — `coollabsio/coolify`
Apache-2.0 · 66,491★ · not a fork · active (v4.7.9, 2026-11-26).
A self-hostable PaaS (Vercel/Heroku alternative): deploy apps,
databases and 360+ one-click services onto your own servers via
Docker, with proxy/TLS handled.

**Relevance:** the alive layer's "hosted like a website" ruling.
Coolify is one way to run a small web service on a VPS or home
box with HTTPS and a dashboard.

**Verdict: not needed for Elaria; do not adopt.** The alive host
is deliberately a near-nothing (webhook + queue + two revocable
tokens); free serverless already gives it a public HTTPS endpoint
with zero maintenance and no control plane. Coolify is a
high-privilege deployment platform (it can launch arbitrary
containers on its host — effectively root with a web UI): a huge
blast radius to babysit a webhook. If the owner ever wants a
general self-hosting platform for other projects, Coolify is a
legitimate Apache-2.0 candidate — as his infrastructure, not as
part of Elaria. Nothing to take, nothing to build.

## Browser Use — `browser-use/browser-use`
MIT · 122,118★ · active (1.0.8, 2026-11-22). Python library that
lets an LLM drive a real Chromium (click, type, navigate), plus a
commercial cloud offering "stealth browsers" and a hosted agent
API.

**Relevance:** REACH (internet eyes) and the grounding problem —
Browser Use's core trick is serialising the page into an indexed
element list the model can act on, the web cousin of our
AT-SPI-first grounding.

**Take (blueprint):** the indexed-element page representation
(semantic elements first, coordinates second — same doctrine as
the NUS pointer), and agent-loop bookkeeping patterns (step
history, retry accounting). For REACH design reference only.

**Refuse (binding rulings):** (1) the runtime itself — we never
install others' agent runtimes, and this one *acts* in a browser
by default (clicks, form-fills, logins), which collides with
Fork 2 (never act-as-owner) and Fork 3 (never evade); (2) its
stealth/anti-detect cloud browsers — precisely the evasion class
the owner ruled terminal-and-journaled, never routed around;
(3) any hosted agent API (third-party custody of sessions and
credentials). REACH stays as designed: official APIs + plain
HTTP, journaled, untrusted-input split, at most one pinned
sandboxed headless Chromium later, behind the same gates.

**Verdict:** blueprint-noted for REACH Phase-1 design reading;
no dispatch, no code, no install.
