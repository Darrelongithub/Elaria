## DEFECTS FOUND

**[TESTED-ONLY] Closed in this increment:**

1. The old QML window only captured previews. It now calls the shipped controller
   and actual standalone queue bridge; local samples are retained only as tests.
2. JavaScript lowercasing alone missed Unicode long-s casefold for the exact
   `yes` vocabulary. The ruled token mapping now matches Python `casefold` for
   these tokens; it does not add synonyms or parse arbitrary intent grammar.
3. Safety review found lifecycle/privacy pitfalls to prevent: stale cached
   private receipts, repeated disconnect signals erasing uncertainty, late
   cleanup unlinking a rebound endpoint, receipt budget blocking redaction,
   and fixture seeding before planning eligibility. The implementation and
   regressions cover those boundaries. Constructor failure also releases its
   lab lease; unknown/interrupted outcomes never automatically resume.
